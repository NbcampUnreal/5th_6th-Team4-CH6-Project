## 🎮 게임 소개

> **오류의 땅, 제킨(Zekin).** 모든 선택이 기록되고 관리되는 '질서의 세계'에서, 플레이어는 시스템이 지워버린 **자유의 근원**이 됩니다.
> 

> 500년간 억눌렸던 옛 통치자의 귀환을 통해, 유저에게 **"진정한 질서란 강요된 통제인가, 아니면 혼란을 감내하는 선택인가?"** 라는 철학적 질문을 던집니다.
> 

> 시연 영상
> 

> **통제된 시스템**의 벽을 부수며 앞으로 **나아가라.**
> 

---

## 🎮 게임 개요

> 📌 **장르 :** 싱글플레이 액션 RPG
> 

> 📌 **플랫폼 :** PC (Unreal Engine 5 기반)
> 

> 📌 **주요 특징 :**
> 

> → **세계관 :** 500년간 봉인된 존재가 다시 호출되는 이야기, 철학적 선택의 연속
> 

> → **전투 시스템 :** 공격, 강공격, 패링, 대시, 스킬, 궁극기로 이루어진 다채로운 전투
> 

> → **AI 몬스터 :** Behavior Tree 기반의 동적 AI, 다양한 상태 전이 및 추적/회피 행동
> 

> → **레벨 디자인 :** 오류의 땅을 테마로 한 몰입감 높은 환경 구성
> 

> → **몰입감 있는 연출 :** 언리얼 엔진 5를 활용한 리얼타임 연출, VFX/SFX
> 

> 1. 완벽한 통제에 던지는 균열
> 

> 📌 **개발 목표 :**
> 

> → 철학적 세계관을 녹여낸 몰입감 있는 게임 경험 제공
> 

> → 동적인 AI와 플레이어의 긴장감 있는 상호작용 구현
> 

> → 팀원 간의 역할 분담을 통한 완성도 높은 결과물 도출
> 

> 이 세계는 한때 하나의 **존재에 의해 설계**되었고, 그 존재는 제거되지 않은 채 **시스템 깊숙이 격리**되었다….
> 

> 📌 **주요 차별점 :**
> 

> → '오류'와 '질서'라는 독창적인 세계관 및 철학적 내러티브
> 

> → 패링·대시·궁극기를 활용한 깊이 있는 전투 설계
> 

> → 날씨 시스템, 환경 연출을 통한 세계 몰입감 강화
>

## 2. 게임 흐름

# 📋 전체 흐름 요약

---

---

| 단계 | 이름 | 핵심 목표 |
| --- | --- | --- |
| Phase 1 | 퀘스트 진행 & 스토리 전개 | 퀘스트를 통해 세계관·스토리를 습득 |
| Phase 2 | 재료 수급 | 전투·탐험으로 제작 재료 확보 |
| Phase 3 | 무기 제작 해금 | 수집한 재료로 강화 무기 언락 |
| Phase 4 | 사막 지역 탐험 | 새 지역 개방 및 적응 |
| Phase 5 | 최종 보스 처치 | 보스 공략으로 엔딩 달성 |

---

## 🗺️ Phase 1 — 퀘스트 진행 & 스토리 전개

- 세부 내용 보기
    
    ### 목표
    
    - 메인 퀘스트를 통해 스토리를 단계적으로 플레이어에게 전달
    - 세계관·캐릭터·갈등 구조를 자연스럽게 소개
    
    ### 주요 구성 요소
    
    - **메인 퀘스트** : 스토리의 핵심 줄기, 다음 지역/단계로 이동하는 조건
    - **서브 퀘스트** : 보조 배경 설명, 선택적 보상 제공
    - **NPC 대화** : 힌트·복선·세계관 정보 전달

---

## ⚔️ Phase 2 — 재료 수급

- 세부 내용 보기
    
    ### 목표
    
    - 무기 제작에 필요한 재료를 전투·탐험·채집으로 확보
    
    ### 재료 수급 방법
    
    | 방법 | 예시 |
    | --- | --- |
    | 몬스터 드롭 | 일반·엘리트 몬스터 처치 |
    | 지역 채집 | 광물, 식물, 유물 수집 |
    | 퀘스트 보상 | 특정 퀘스트 완료 시 지급 |
    | 상점 구매 | 골드로 일부 재료 구입 |

---

## 🔨 Phase 3 — 무기 제작 해금

- 세부 내용 보기
    
    ### 목표
    
    - 수집한 재료를 소비해 강화 무기를 제작하고, 새로운 무기 슬롯/스킬을 언락
    
    ### 제작 흐름
    
    1. 대장장이 NPC 또는 제작 메뉴 접근
    2. 보유 재료 확인
    3. 무기 레시피 선택 → 제작
    4. 해금된 무기 장착 및 스킬 확인

---

## 🏜️ Phase 4 — 사막 지역 탐험

- 세부 내용 보기
    
    ### 목표
    
    - 새로 개방된 사막 지역을 탐색하고, 최종 보스 전투를 준비
    
    ### 탐험 포인트
    
    | 장소 | 특징 |
    | --- | --- |
    | 사막 입구 | 경비 적·튜토리얼 전투 |
    | 유적 지대 | 숨겨진 퀘스트·아이템 존재 |
    | 사막 심부 | 엘리트 몬스터, 보스 전초전 |
    | 보스 던전 앞 | 최종 보스 입장 조건 확인 |

---

## 💀 Phase 5 — 최종 보스 처치

- 세부 내용 보기
    
    ### 목표
    
    - 최종 보스를 처치하여 메인 스토리 엔딩 달성
    
    ### 전투 준비 체크
    
    - [x]  권장 레벨 / 장비 수치 충족
    - [x]  소모 아이템(포션 등) 충분히 보유
    - [x]  보스 패턴 사전 파악 (서브 퀘스트 힌트 등)
    - [x]  파티 / 빌드 세팅 완료
